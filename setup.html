1. Create Your School Spreadsheet

Each school should use its own private copy of the Vocational Tracker spreadsheet. The spreadsheet holds the school's student data and security settings.

Make a Copy of the Spreadsheet
Important: Keep spreadsheet access limited to the small number of staff who truly need spreadsheet-level administration. Staff entering evaluations do not need access to the spreadsheet.

2. Open the Spreadsheet

Open the copy you just created. The Vocational Tracker script prepares the instance automatically when the spreadsheet opens.

Open your copied spreadsheet
Give the sheet a school-specific name so it is easy to identify later.
B
Let the tracker prepare itself
The script checks for the required tabs and settings and creates anything that is missing. It is safe for this check to happen again later.
C
Look for the Vocational Tracker menu
In the Google Sheets menu bar, you should see Vocational Tracker. If it does not appear immediately, refresh the spreadsheet once.
No manual initialSetup step: You should not need to open the Apps Script editor, select a function, or read anything from the Execution log just to initialize the spreadsheet.

3. Create the First Administrator

Administrator access is managed inside the spreadsheet instead of through a shared password. Each administrator receives their own personal code. Administrators automatically receive report access too, so they do not need a separate report-viewer account or second code.

A
Open Vocational Tracker → Setup & Credentials
This opens the secure sidebar that is available only from inside the spreadsheet.
B
Create the first administrator
Enter your name and use the sidebar's first-admin setup control.
C
Copy your personal admin code
The code is shown once. Save it in a secure password manager or another approved secure location.
Your code cannot be recovered. Only a one-way hash is stored. If you lose the code, a spreadsheet administrator can issue you a new one from the Setup & Credentials sidebar without changing anyone else's admin code.
First authorization: Google may ask you to authorize the bound Apps Script the first time you use the sidebar. If your organization shows an unverified-app warning for this internal script, follow your district's normal Apps Script approval process.
rocket_launch

4. Deploy the Web App

This is the one part Google requires you to do manually. The deployment creates the private backend URL used by your school's Vocational Tracker pages.

  1. In the spreadsheet, go to Extensions → Apps Script.
  2. Click Deploy → New deployment.
  3. Click the gear icon next to Select type and choose Web app.
  4. Set Execute as: Me.
  5. Set Who has access: Anyone.
  6. Click Deploy.
  7. Copy the Web app URL. It should end in /exec.
Use the /exec URL. Do not use the /dev testing URL. The /dev version requires Google authentication and will not work correctly for the job-site entry flow.
Later code updates: Do not create another deployment. Use Deploy → Manage deployments → Edit → New version. That keeps the same backend URL and prevents every school link from breaking.
link

5. Connect & Finish

Paste the Web App URL from the previous step. The wizard will confirm that the deployment is reachable and remember it for this Vocational Tracker instance.

Before going live

  • Add your real students, job sites, and tasks.
  • Add viewer codes only for staff who need Reports but are not administrators.
  • Add additional administrators only when they need admin-level access; admins automatically inherit report access.
  • Generate a fresh entry QR and test one sample submission.
  • Confirm a viewer can open Reports but cannot reach Admin.
